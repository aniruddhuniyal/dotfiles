## $ whoami

```console
user@machine:~$ cat about.txt
Config files for a fresh machine to feel like home in minutes.
One folder per tool. Symlinks over copies. No secrets, ever.
```

## $ tree

```console
user@machine:~/dotfiles$ tree -L 2
.
├── shell/          # aliases, functions, prompt, exports
├── git/            # gitconfig, global ignore, commit template
├── editor/         # settings, keybindings, extensions list
├── terminal/       # emulator theme and font setup
├── scripts/        # small helpers used daily
├── install.sh      # bootstrap: links everything into place
└── README.md
```

## $ ./install.sh

```console
user@machine:~$ git clone https://github.com/aniruddhuniyal/dotfiles.git ~/dotfiles
user@machine:~$ cd ~/dotfiles
user@machine:~/dotfiles$ ./install.sh

[ok] backed up existing configs to ~/.dotfiles_backup/
[ok] linked shell/.bashrc      -> ~/.bashrc
[ok] linked git/.gitconfig     -> ~/.gitconfig
[ok] linked editor/settings    -> ~/.config/editor/settings
[done] 3 links created, 0 errors
```

The script moves any existing file to `~/.dotfiles_backup/` before linking, so nothing gets destroyed.

### Only want one piece?

```console
user@machine:~$ ln -s ~/dotfiles/git/.gitconfig ~/.gitconfig
```

## $ git pull

```console
user@machine:~$ cd ~/dotfiles && git pull && ./install.sh
```

Everything is symlinked, so edits made in place show up in the repo right away. Check with `git diff`, then commit.

## $ man dotfiles

| Principle | Why |
| --- | --- |
| One folder per tool | Adopt or drop pieces independently |
| Symlinks, not copies | The repo stays the source of truth |
| No secrets | Public repo, so nothing sensitive goes in |
